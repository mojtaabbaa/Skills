## 1. Search-Intent-First Opening & Body Axis Matrix (Rule 0)

| :--- | :--- | :--- |

| **`انواع [X]` (Taxonomy)** | `1–2` line verdict + immediate list of actual types (`انواع [X] عبارت‌اند از:` -> `* ...`) | Center early comparison table & balanced `### H3` sections directly around each type and its ideal user. |

## 2. The 4-Part Introduction Anatomy (80–130 Words)
1. **Direct Verdict (`1–2` sentences):** Immediate answer (Yes/No, numeric count, safe vs faulty split) with the primary keyword in the first `150` words. Zero slow storytelling or clichés (`در دنیای امروز...`).
2. **Prioritized Summary (`1. 2. 3. 4.` or `*`):** Ordered list for sequential steps/phases/criteria; bullets if strictly non-sequential.
3. **[Optional Project Service CTA Slot]:** Only if the active workspace's local `.agents/skills/brand-*/SKILL.md` authorizes inline CMS shortcodes here.
4. **Snapshot Box (`## [موضوع] در یک نگاه` at `H2` level):** `1` framing line + `3–4` crisp `* **Bold:**` bullets -> Conditional Reader Promise (*«اگر می‌خواهید بدانید...»*) -> `---` divider.

## 3. The 3 Universal UX-First Content Archetypes

### Archetype 1: Timeline, Duration & Behavioral Schedule (`قالب جدول زمانی و مراقبت/عملکرد`)
1. **Metadata + 4-Part Intro** (exact duration + ordered timeline `۱..۴` + `## در یک نگاه` + `---`).
2. **`## جدول زمانی [موضوع]`:** `1–2` line answer + Single Master Table (`| بازه / مرحله | وضعیت و مجاز بودن | ریسک اصلی | توصیه کلیدی |`) + **`نکته‌ای که در این جدول پنهان است:`** (`2` `*` bullets) + `---`.
3. **`## راهکارهای اصولی و نحوه ایمن اجرا / نگهداری` *(Action FIRST)*:** Balanced `###` blocks with **Ordered Steps (`1. 2. 3.`)** (`< 25w`/item).
4. **`## کارهای ممنوعه و اشتباهات رایج`:** **Ordered Checklist (`1. 2. 3. 4.`)**.
5. **`## دلایل فنی / علمی تغییرات در هر بازه`:** `1–2` line answer + **Bullets (`*`, `< 25w`)**.
6. **`## علائم هشدار / زمان توقف یا تعویض فوری`:** Red-Flag Table (`| نشانه | علت احتمالی | اقدام فوری |`).
7. **Project E-E-A-T Bridge -> Non-Redundant `## جمع‌بندی` (`2–3` lines + ONLY `۱..۴` mistakes) -> `4–6` FAQs -> Direct-URL `## منابع`.**

### Archetype 2: Diagnostic Dual — Normal vs. Faulty + Urgent Fix (`قالب تشخیصی دوگانه و اقدام فوری`)
1. **Metadata + 4-Part Intro** (normal vs faulty/fake split + ordered triage `۱..۴` + `## در یک نگاه` + `---`).
2. **`## جدول تشخیصی؛ تمایز [حالت طبیعی] از [مشکل/تقلب واقعی]`:** High-contrast table (`| نشانه / معیار | حالت عادی | وضعیت خطرساز یا فیک | اقدام لازم |`) + **`نکته‌ای که در این جدول پنهان است:`** (`2` `*` bullets) + `---`.
3. **`## راهکارهای فوری و تست‌های عملی عیب‌یابی` *(Solutions FIRST)*:** Balanced `###` blocks with **Ordered Steps (`1. 2. 3.`)**.
4. **`## اشتباهات و کارهای ممنوعه‌ای که وضعیت را بدتر می‌کنند`:** **Ordered Checklist (`1. 2. 3. 4.`)**.
5. **`## علت‌های طبیعی و بی‌خطر`** (`*` bullets) + **`## علت‌های غیرطبیعی و خطرساز`** (`*` bullets; zero unsafe DIY fixes for severe hazards).
6. **`## علائم هشدار و خط قرمزهای فوری`:** Red-Flag Table (`| علامت هشدار | احتمال فنی/بالینی | فوریت اقدام |`).
7. **Project E-E-A-T Bridge -> Non-Redundant `## جمع‌بندی` -> `4–6` FAQs -> Direct-URL `## منابع`.**

### Archetype 3: Candidacy, Types, Anatomy & Comparison (`قالب انواع، کارکرد و مقایسه`)
1. **Metadata + 4-Part Intro** (direct type list or 2-layer `بهترین` answer + `## در یک نگاه` + `---`).
2. **`## جدول مقایسه جامع انواع و کاربردها`:** Focused matrix (`| نوع / مدل | ساختار / جنس | مناسب برای | مزیت و محدودیت |`) + **`نکته‌ای که در این جدول پنهان است:`** (`2` `*` bullets) + `---`.
3. **`## راهنمای انتخاب سریع و نکات نگهداری عملی` *(Actionable Value FIRST)*:** Balanced `###` blocks with **Ordered Steps (`1. 2. 3.`)**.
4. **`## اشتباهات رایج در انتخاب و نگهداری`:** **Ordered Checklist (`1. 2. 3. 4.`)**.
5. **`## بررسی تخصصی هر نوع و نقش فنی آن`:** `H2` (`1–2` line direct answer) -> balanced `### H3` subsections with short intros + **Bullets (`*`, `< 25w`)**.
6. **Optional Failure/Red-Flag Table** (only if genuinely distinct safety/fraud thresholds exist).
7. **Project E-E-A-T Bridge -> Non-Redundant `## جمع‌بندی` -> `4–6` FAQs -> Direct-URL `## منابع`.**

## 4. Micro-Formatting, SERP Gap & YMYL Safety Standards

* **2-Line Visual Ceiling:** Never write >2 lines (3 max, ~30–45 Persian words) without breaking into a table, list, or bold callout (`نکته کاربردی:` / `نکته علمی:`).
* **Single-Table Discipline:** Avoid overlapping duplicate summary tables; reserve a second table strictly for urgent red-flag thresholds.
* **SERP + International Gap Methodology:** Cover all baseline Iranian SERP topics + fill blind spots using primary international standards (`PubMed`, `Cochrane`, `JAMA`, `USDA FoodData Central`, `KDIGO`, `FDA/EPA`, `SCA`, `ISO`, `UN ECE`, `FSC`, `BIFMA`). Always acknowledge realistic ranges and never fabricate study numbers or 404 sub-URLs.
* **YMYL Medical & Nutrition Precision Gate (Mandatory on Health/Diet/Surgery Topics):**
  1. Always distinguish **Raw (خام) vs. Cooked (پخته/کبابی/آب‌پز)** per `100g` and **Skin-on vs. Skinless (`با پوست` vs `بدون پوست`)**.
  2. For renal/clinical topics (`CKD`), distinguish pre-dialysis vs dialysis protein targets and explicitly address Phosphorus, Potassium, and Purine/Uric Acid.
  3. Include a clear non-alarmist medical disclaimer (*«این مطلب صرفاً جنبه آموزشی دارد و جایگزین مشاوره پزشک یا متخصص نیست»*).
  4. Never place soft-sell product links inside urgent/emergency red-flag symptom warnings.
* **On-Demand Image Brief Rules (Zero On-Site Blog Clutter):**
  * NEVER insert `تصویر ۱/۲/۳` markers or prompt blocks inside clean on-site blog prose.
  * Only when the user explicitly requests image briefs (or in off-site reportages), provide separately: `ایده تصویر به فارسی` + English photorealistic prompt (`no text, clean composition`, avoiding complex multi-hand anatomy artifacts) + concise Persian `Alt Text` embedding the topic naturally. Never propose AI-generated images of real client physical facilities/roasteries/factories.
