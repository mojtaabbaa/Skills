# Engine 06: Advertorials (`rep/`), External Blogs & 5-Platform Off-Page PR

Use this engine for all off-site SEO deliverables: publisher advertorials (`رپورتاژ آگهی`), external Web 2.0 / paraphrased guest blogs, 5-platform social distribution campaigns, and anchor text audits. Always load the active workspace's local `.agents/skills/brand-*/SKILL.md` skill first to check which off-page outreach channels are active for that project (e.g., reportage `rep/` mode only vs. full external blog and social distribution).

---

## 1. Track A: Publisher-Calibrated Advertorials / Reportage (`rep/`)

### Core Principles:
* **75/25 Editorial Value Rule (or 90/10 for strict magazines):** Deliver genuine standalone editorial depth so editors publish cleanly and readers trust the brand as the logical solution.
* **Word Count Scope:** Publisher word limits (e.g., `<= 1,400` on capped portals or `~1,550–1,850` on "up to 2,500" portals) count **`# H1` + body + conclusion + FAQs ONLY** — bottom `**متا تایتل:**` and `**متا دسکریپشن:**` below `---` are EXCLUDED from the word cap.
* **Strict Reportage Exclusions (`تفاوت با بلاگ اصلی`):**
  * **ZERO `## منابع` bibliography block** (unless host publisher explicitly requests citations).
  * **ZERO unrequested internal blog cross-links.**
  * **ZERO `[elementor-template]` shortcodes.**
  * **ZERO Search-Intent Hijacking:** Pure `خواص [X]` reportages focus 100% on benefits/science (NO cooking recipes); pure `طرز تهیه` focuses on recipes/execution.
* **Early & Distributed Anchor Placement (`حداکثر ۱ لینک برای هر URL`):**
  * Insert **ONLY the exact requested target anchors** (`1` clickable Markdown hyperlink per destination URL; verify exact percent-encoded Persian slugs like `چ` -> `%DA%86`!).
  * NEVER bunch all anchors at the closing CTA! Place Link #1 naturally **early in the body (`~8%–25%`)** and Link #2 in a separate mid-body section (`~35%–70%`), optionally reinforced by subtle natural plain-text echoes (`1–2x`).
* **Image Packaging (`rep/` Mode Exception):** Include `تصویر 1/2` placement markers or bottom `پیشنهاد بسته تصاویر` ONLY when the host publisher or the active workspace's local brand skill (`rep/` convention) explicitly mandates them; otherwise omit `تصویر ۱/۲` markers cleanly.

### The 4 Publisher Format Archetypes:
| Format | Target Media Outlets | Structural Signature |
| :--- | :--- | :--- |
| **Format A: Health & Wellness** | جسارت، سیمرغ، بدونیم، ساتین، سلامت | Direct verdict (Positives vs. Cautions) -> **Pre-H2 Summary Table** -> Demographic/clinical H2s + medical disclaimer -> Organic brand bridge (quality/purity solves risk) -> 3–4 FAQs |
| **Format B: Culinary & Practical Craft** | فودمز، چاشنی، یاس لایف، چرخونکی | Simplest execution steps (`۱..۴`) -> **Pre-H2 Ratios/Methods Table** -> Device/method H2s -> Organic brand bridge (fresh raw material/precision prep) -> 3–4 FAQs |
| **Format C: B2B & Industrial Manufacturing** | چیکا، صمت، اگروفود | High-level production phases -> Sequential Stage H2s -> Capacity, QC, moisture/material specs, logistics SLAs (zero poetic fluff) |
| **Format D: Local City Discovery & Fair Listicle** | کافه کجایی، اخبار مشهد، مشهد فوری، ادزیو | Fair, non-defamatory city directory/listicle using ONLY verified competitor facts -> Factual positioning of target brand with verified NAP & differentiators |

## 2. Track B: External Paraphrased / Web 2.0 Blogs (`پارافریزی` — 700–1,000 Words)
* **Anti-Duplicate & Anti-Cannibalization:** Never spin or copy-paste on-site blogs. Every external blog targeting the same money page must tackle a **fresh, distinct sub-angle** (e.g., physics/materials, usage mistakes, comparison angle).
* **Length:** Strictly **`~700–1,000` words** (NOT padded to 2,000w on-site blog rules).
* **Linking:** Embed `1` verified target URL (`max 2` if publisher permits) cleanly mid-body (`~40%–70%`), never stuffed in sentence 1.

## 3. Track C: 5-Platform Social Distribution Suite (`سوشال`)

Never copy-paste identical text across networks. Adapt tone and linking to each community's native culture:

| Platform | Length & Format | Native Community Persona | Linking Rule |
| :--- | :--- | :--- | :--- |
| **Reddit** | `250–400` words (`1` post) | **The Skeptical Peer:** Conversational, genuine discussion or troubleshooting breakdown. Zero ad copy or corporate buzzwords! | Subtle contextual reference only if truly enriching; never "Buy now". |
| **Facebook** | `150–250` words (`1` post) | **Helpful Community Member:** Warm, practical household/lifestyle tip solving a daily dilemma. | Calm informational recommendation link at the conclusion. |
| **X (Twitter)** | `6–10` connected tweets (`🧵`) | **Rapid-Fire Specialist:** Tweet 1 sharp hook/insight (`🧵`); Tweets 2–7 standalone tips/metrics/mistakes; Final tweet summary. | Target URL + natural anchor in penultimate or final tweet. |
| **Pinterest** | `80–120` words + **Infographic Brief** | **Visual Curator:** Aesthetic, inspiring, search-friendly Pin Title, Description, Alt Text, and clean infographic layout brief. | Direct destination link attachment. |
| **Quora** | `300–500` words (`1` answer) | **In-Depth Consultant:** Structured, authoritative Q&A with numbered criteria and unbiased technical rationale. | Natural named citation as an illustrative example/reference. |

*(Optional for Persian medical/tech PR: **Virgool** `800–1,200` words educational deep dive with 1 contextual anchor.)*

## 4. Off-Page Anchor Text Diversity & Integrity Policy
Avoid algorithmic over-optimization across a campaign portfolio:
* **Brand / Brand + Domain (`~30–40%`):** Brand name, official domain.
* **Partial / Descriptive Contextual (`~30–35%`):** Natural Persian descriptive phrases fitting surrounding grammar.
* **Exact Match Commercial (`~15–25%`):** Exact target commercial keyword (verified against target URL to prevent wrong-SKU links!).
* **Naked URL / Natural Generic (`~10%`):** Direct `https://...` or clean reference phrase.
* **Zero Fabrication Rule:** NEVER invent fake 5-star reviews (`"من ۵ بار سفارش دادم عالی بود"`), fake promo codes, fake credentials, or defamatory attacks on competitors.
