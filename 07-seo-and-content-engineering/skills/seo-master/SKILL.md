# Unified Global Persian SEO Master Engine (`seo-master`)

This single global master skill consolidates all domain-independent Persian SEO methodologies, editorial v2 standards, technical WordPress/WooCommerce/Rank Math playbooks, commercial copywriting blueprints, off-page PR systems, and RTL `.docx` generation across every workspace.

> [!CAUTION]
> **Hard Brand-Isolation & Conflict-Resolution Gate (جداسازی مطلق هویت از ساختار):**
> 1. `seo-master` enforces **universal SEO structure, technical methodology, and quality rules ONLY**. It NEVER stores client URLs, phone numbers, Elementor IDs, or brand claims.
> 2. Before drafting or auditing any client deliverable, **MUST load the active workspace's local Brand Identity Skill** (`.agents/skills/brand-*/SKILL.md`) to inject exact orthography (`ZWNJ` vs `Zero-ZWNJ`), tone, metadata placement, verified sitemap URLs, shortcodes, and claim boundaries.
> 3. **Precedence Hierarchy:** Explicit User Prompt in current chat > Active workspace's local `.agents/skills/brand-*/SKILL.md` (for identity, orthography, URLs, metadata placement, and word-budget overrides) > `seo-master` universal structural/technical rules.
> 4. **Zero-Hallucination & Source-Fallback Rule:** Never invent live rankings, GSC metrics, WooCommerce product IDs, Elementor shortcode IDs, or unverified sub-URLs (`404`). If live data, site HTML, or workspace files are missing, inspect the actual workspace/source files directly or explicitly ask the user.

## 1. The 10 Universal v2 SEO & Editorial Golden Rules (Always Active)

0. **Search-Intent-First Axis (`قاعده تشخیص اینتنت پیش از چیدمان`):** Lock BOTH Paragraph 1's opening answer AND the main body axis strictly to the searcher's primary query type BEFORE choosing formatting:
   * **`طرز تهیه / نحوه انجام / آموزش ساخت [X]`:** Open immediately with ordered core execution steps (`مراحل ... به ترتیب زیر است: ۱. ... ۲. ...`) — NEVER hijack the intro with a buying debate.
   * **`خواص [X]`:** Focus 100% on nutritional science, active compounds, health outcomes, target groups, and contraindications — **NEVER dilute or hijack with cooking recipes (`طرز پخت`)**.
   * **`انواع [X]`:** Open Paragraph 1 directly with the categorical type list (`انواع [X] عبارت‌اند از:` -> `* ...`).
   * **`بهترین [X]`:** Deliver a **2-Layer Direct Answer**: (A) consensus overall winner in `1–2` lines + (B) conditional breakdown by need (`[گزینه]: در [معیار] بهترین است؛ اگر [شرایط] دارید، این بهترین است`).
   * **`چند روز / تا کی / چه زمانی [X]`:** Lead immediately with exact duration/window + chronological `۱..۴` phases.
   * **`علت / چرا / تشخیص [X]`:** Split **حالت طبیعی/ایمن** vs **نقص/خطر/تقلب واقعی** in sentence 1 + quick triage checks `۱..۴`.
   * **`قیمت / تفاوت [X]`:** Lead with pricing drivers / core contrast + single focused comparison matrix.
1. **UX-First Section Ordering:** Immediate Direct Answer -> Single Focused Early Table + **`نکته‌ای که در این جدول پنهان است:`** (`2` `*` bullets) -> **Actionable Steps / Immediate Solutions (`1. 2. 3.`)** -> **Prohibited Mistakes (`1. 2. 3.`)** -> Deep Theory / Mechanisms / Balanced `###`s (`*`, `< 25w`/item) -> Optional Red-Flag Table -> Brand E-E-A-T Bridge -> Non-Redundant `جمع‌بندی` -> `4–6` FAQs -> Verified Direct-URL `## منابع`.
2. **Direct Answer Under EVERY `## H2`:** Separate major `## H2` sections with `---`. Open every `## H2` with `1–2` direct-answer sentences BEFORE any `### H3`, table, or list. Never stack headings (`H2 -> H3`).
3. **2-Line Visual Ceiling & Semantic List Grammar:** Cap continuous narrative prose at **2 lines (`3` max)**. Use **Ordered Lists (`1. 2. 3.`)** for chronological phases, sequential how-to steps, triage checks, prohibited checklists, and conclusion mistakes; use **Bullets (`*`)** for snapshots (`## [موضوع] در یک نگاه`), post-table insights, unordered traits/causes, and citations.
4. **Compact Word-Budget Discipline (By Deliverable Type):**
   * Full v2 Blog Article: **`1,400–1,800` words (`< 2,000` default cap)**; expand only when project brief explicitly authorizes it.
   * Surgical Blog Insertion: **`200–500` words** per H2/H3 block with exact `📍 محل قرارگیری`.
   * Category `Read More` Update: **`~250` dense words** (zero fluff/CTA/FAQ).
   * Off-Page Paraphrased Blog: **`700–1,000` words**.
   * Publisher Advertorial (`rep/`): Strictly follow publisher cap on `# H1 + body` (bottom Meta excluded).
5. **High-CTR Metadata Hygiene:** SEO Title `<= 60` chars (numeric/criterion CTR formula, ZERO `!`, distinct from H1); Meta Description `130–155` chars; follow target project's exact metadata placement (top block vs `.md` bottom block).
6. **Non-Redundant `## جمع‌بندی`:** `2–3` crisp lines in target brand's authorized voice + **ONLY ONE ordered mistake list (`مهم‌ترین اشتباهاتی که باید از آن‌ها دوری کنید: ۱. ۲. ۳. ۴.`)** — NEVER stack a duplicate bullet summary right above it!
7. **Max 1 Link Per Unique URL & Zero Legacy Imitation:** Cap EVERY unique destination URL at `1` occurrence per article (never duplicate homepage `/` beside a `/` banner/CTA shortcode). Use ONLY verified live URLs from the active workspace's local `.agents/skills/brand-*/SKILL.md`; NEVER imitate low-quality prose of older live blog posts.
8. **Strict Mode Purity:** On-site blog deliverables NEVER leak reportage image cues (`تصویر ۱/۲/۳`), raw `{...}` placeholders, or inline alt/SEO dumps into prose. Off-site `rep/` reportages NEVER include `## منابع`, internal blog cross-links, or Elementor shortcodes.
9. **Clean External Citations & RTL DOCX Delivery:** Cite specific direct verified URLs (never bare homepages if a real article/guideline URL is verified, never invent 404 sub-URLs, always strip `?utm_source=`). Convert finished Persian `.md` drafts to clean RTL Word documents via [`scripts/md_to_docx.py`](./scripts/md_to_docx.py) (`--strip-zwnj` ONLY when the active project's local brand skill mandates Zero-ZWNJ; `--meta-bottom` when bottom metadata is needed).

## 3. Local Brand Discovery (Pair With `seo-master`)

Before drafting, auditing, or converting any client deliverable, locate and load the active workspace's local Brand Identity Skill at **`.agents/skills/brand-*/SKILL.md`** to inject all project-specific rules:

* **Orthography Contract:** Standard Persian `ZWNJ` (`\u200c`) vs. strict `Zero-ZWNJ` (`--strip-zwnj` in `md_to_docx.py`), punctuation restrictions, and spelling conventions.
* **Voice, Tone & Claim Boundaries:** Authorized brand terminology, forbidden brand mentions or superlatives, YMYL disclaimers, and verified business facts/NAP.
* **Metadata Placement & Word Budgets:** Top metadata block (`# مشخصات سئو و متادیتا`) vs. bottom `.md` metadata block (`--meta-bottom`), plus any project-specific word-count overrides.
* **Verified Live URLs & Slug Rules:** Approved internal links, canonical archive paths, and permanent workspace/folder exclusions.
* **CMS & Elementor Shortcodes:** Authorized inline banner/CTA shortcodes and template IDs (never invent or carry shortcodes across workspaces).
