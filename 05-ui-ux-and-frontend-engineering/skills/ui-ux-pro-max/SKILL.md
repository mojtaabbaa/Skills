# UI/UX Pro Max

## Overview
Comprehensive UI/UX design intelligence skill for AI coding assistants. Injects structured design tokens, color theory, typography scales, accessibility guidelines, and component patterns into Claude Code, Cursor, and Windsurf.

- **Source Repository**: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
- **Safety Profile**: Safety: The core UI/UX Pro Max search scripts are offline, standard-library Python that only read bundled data and write files on explicit --persist, but the plugin and CLI also install companion design skills whose optional scripts call external AI image APIs with your keys or run npx.

## Implementation Best Practices
1. Integrate cleanly with UI design systems, token architectures, and theme variables.
2. Adhere to strict WCAG 2.2 contrast ratios and minimum 44x44px touch targets.
3. Preserve responsive layouts across desktop, tablet, and mobile viewports.
4. Support bi-directional layouts (RTL/LTR) gracefully.
